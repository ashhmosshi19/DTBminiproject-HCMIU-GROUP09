# DTBminiproject-HCMIU-GROUP09
This project encompasses Entity Relationship Diagram, Database Design, and User Interface Design. The purpose of this system is assist to manage bus operations, drivers, routes, and stations efficiently.
This is a basic management system designed to manage various datasets. That this system allows the manager to control multiple functions on drivers, buses, routes and stations through user interface with fundamental purpose such as show, search, and update.
On the "Home Page" of website display the introduction of developer group, the objective of the website, features of system and include contact informations.
The header located on the top of the website, providing four main functional buttons: HOME, DATABASE, SEARCH, and UPDATE.
Firstly, the search button allows the user to find the target informatio though the database table, and there is corresponding space for typing in your keyword input as ID, name, gender, etc. And when the user clicks the "Search" button, the form executes a POST request, transmitting the selected table type and input keyword to the result.php file. Moreover, it will search for each entered word using the corresponding code. The system verifies if both the search keyword and the selected table type are provided. 
If the input is correct, or does not exist. The direction to result.php will show the warning post. Otherwise, the result is illustrated in table as shown below.
Last one, the update button allows the user to update the bus information. Same as active, inactive or maintennace. Also we can update the date of the bus. If the system update successfully, then it will show a confirmation and detailed update information screen. In case of entering duplicated update information, a notification message will appear.
